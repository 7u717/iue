微积分公式速查 Calculus
▼
基础积分表
∫ 1/x dx = ln|x| + C
∫ e^(ax) dx = (1/a)e^(ax) + C
∫ a^x dx = a^x/ln(a) + C，a ≠ 1
∫ sin(ax) dx = -(1/a)cos(ax) + C
∫ cos(ax) dx = (1/a)sin(ax) + C
∫ sec²(ax) dx = (1/a)tan(ax) + C
∫ cosec²(ax) dx = -(1/a)cot(ax) + C
∫ tan(ax) dx = (1/a)ln|sec(ax)| + C
∫ cot(ax) dx = (1/a)ln|sin(ax)| + C
∫ sec(ax) dx = (1/a)ln|sec(ax)+tan(ax)| + C
∫ sinh(ax) dx = (1/a)cosh(ax) + C
∫ cosh(ax) dx = (1/a)sinh(ax) + C
∫ sech²(ax) dx = (1/a)tanh(ax) + C
∫ cosech²(ax) dx = -(1/a)coth(ax) + C
∫ dx/(a²+x²) = (1/a)tan⁻¹(x/a) + C
∫ dx/(a²−x²) = (1/a)tanh⁻¹(x/a) + C，|x| < a
∫ dx/(a²−x²) = (1/a)coth⁻¹(x/a) + C，|x| > a > 0
∫ dx/(a²−x²) = (1/(2a))ln|(a+x)/(a−x)| + C，x² ≠ a²
∫ dx/√(a²−x²) = sin⁻¹(x/a) + C
∫ dx/√(x²+a²) = sinh⁻¹(x/a) + C
∫ dx/√(x²−a²) = cosh⁻¹(x/a) + C，x ≥ a > 0
Ch1A · 偏导数 & 梯度
∂f/∂x → 固定 y（及其他变量），对 x 求普通导数
∇F = (∂F/∂x, ∂F/∂y, ∂F/∂z) → 梯度向量 = 隐曲面 F(x,y,z)=C 的法向量
线性函数 F=ax+by+cz → ∂F/∂x=a, ∂F/∂y=b, ∂F/∂z=c（直接读系数）
Ch1B · 链式法则
二元单参：dz/dt = ∂z/∂x · dx/dt + ∂z/∂y · dy/dt
三元单参：dF/dt = ∂F/∂x·dx/dt + ∂F/∂y·dy/dt + ∂F/∂z·dz/dt = ∇F · (dx/dt)
隐函数：F(x,y,z)=C → dF/dt = 0，可解出未知的 dz/dt
化简：cos²t − sin²t = cos(2t)　　sin²t + cos²t = 1
Ch2A · 换元积分速查表
√(a²+x²) → x=a·tan(u) 或 x=a·sinh(u)
√(a²−x²) → x=a·sin(u) 或 x=a·tanh(u)
√(x²−a²) → x=a·sec(u) 或 x=a·cosh(u)
圆三角恒等式：1+tan²u=sec²u　　1−sin²u=cos²u　　sec²u−1=tan²u
双曲恒等式：cosh²u−sinh²u=1　→　1+sinh²u=cosh²u　，　1−tanh²u=sech²u
回代（以 x=a·tan(u) 为例）：三角形对边=x，邻边=a，斜边=√(a²+x²)
定积分换元：上下限也要换成 u；如 x=3sec(u), x=3→u=0, x=6→u=π/3
扇形面积速算：∫₀ᵃ √(a²−x²) dx = πa²/4，例如 a=4 得 4π
f'/f 型：∫ f'(x)/f(x) dx = ln(abs(f(x))) + C
基础对数积分：∫1/x dx = ln(abs(x)) + C
sec 积分：∫sec(x) dx = ln(abs(sec(x)+tan(x))) + C
配方反三角：∫ 1/((x+h)²+a²) dx = (1/a) arctan((x+h)/a)+C
反三角标准式：∫1/(x²+a²) dx = (1/a) arctan(x/a)+C
还原公式例：Iₙ=∫₀¹xⁿe⁻ˣdx → Iₙ=nIₙ₋₁−1/e；Iₙ=∫secⁿx dx → Iₙ=secⁿ⁻²(x)tan(x)/(n−1)+(n−2)Iₙ₋₂/(n−1)
降阶公式核心：先用分部积分/恒等式把 Iₙ 写成 Iₙ₋₁ 或 Iₙ₋₂，再递推到 base case
Beta Function：B(m,n)=∫₀¹xᵐ⁻¹(1−x)ⁿ⁻¹dx；B(m,n)=B(n,m)
Beta 递推：B(m,n)=((m−1)/(m+n−1))B(m−1,n)=((n−1)/(m+n−1))B(m,n−1)
整数 Beta：B(m,n)=((m−1)!(n−1)!)/(m+n−1)!，适合快速验算
∫sech(u)du 法①：令 t=eᵘ → 2arctan(eᵘ)+C
∫sech(u)du 法②：令 t=sinh(u) → arctan(sinh u)+C
线性代数公式速查 Linear Algebra
▼
向量空间 & 子空间
子空间判定：① 0∈W ② u,v∈W ⇒ u+v∈W ③ c∈R,v∈W ⇒ cv∈W
span{v₁,...,vₖ} = 所有线性组合 c₁v₁+...+cₖvₖ，必定是子空间
线性无关：c₁v₁+c₂v₂+...+cₖvₖ=0 只有零解；否则线性相关
齐次系统 Ax=0：自由变量存在 ⇒ 有非零解 ⇒ 列向量线性相关
行化简判定：每一列都有主元 ⇒ 只有零解 ⇒ 列向量线性无关
含零向量的集合一定线性相关；ℝⁿ 中超过 n 个向量也一定线性相关
矩阵 & 秩
行列式（2×2）：det[a b; c d] = ad − bc
行列式（3×3）：沿第一行展开，符号 + − +
列空间 col(A) = span{A 的列向量}；b∈col(A) ⇔ Ax=b 有解
Rank-Nullity：rank(A)+nullity(A)=n（n 是列数）
特征值 & 几何
特征值：det(A−λI)=0；特征向量：(A−λI)v=0 且 v≠0
对角化：A=PDP⁻¹，P 的列是特征向量，D 的对角线是特征值
正交：u·v=0；单位向量：‖v‖=1；投影：proj_v(u)=(u·v/v·v)v
Maple 指令速查 Maple
▼
函数定义
🖥️ (x, y) -> 6*x^5*y^3*sin(9*x - y)　← 箭头算子，不写 f:= 和 ;
🖥️ f := (x, y) -> expr　← 赋值给变量 f 时才加 f :=
偏导数
🖥️ diff(f(x,y), x)　← ∂f/∂x
🖥️ diff(f(x,y), x, x, y)　← ∂³f/∂y∂x²（先x求2次，再y求1次）
🖥️ diff(f(x,y), x$2, y)　← 同上，简写方式
🖥️ evalf(D[1$4, 2$3](f)(-2,-1), 10)　← 数值偏导，10位有效数字
D[1] = 对第1个变量(x)求导，D[2] = 对第2个变量(y)求导
三维画图
🖥️ plot3d(x^2 + y^2, x=-3..3, y=-3..3)　← 区间用 .. 不是 :
数学函数写法
🖥️ arcsin(x)　arccos(x)　arctan(x)　← 反三角
🖥️ arcsinh(x)　arccosh(x)　arctanh(x)　← 反双曲
🖥️ sqrt(x)　exp(x)　ln(abs(x))　← 根号、e次方、绝对值对数
🖥️ int(expr, x)　int(expr, x=a..b)　← 不定/定积分；π 写 Pi，e 写 exp(1)
🖥️ sin(x)^2　tan(x)^2　← 平方写在括号后（不是 sin²(x)）
🖥️ simplify(expr)　← 化简结果，导数后常用
部分分式 · ODE · 连乘 · Taylor
🖥️ convert(p/q, parfrac, x)　← 对 p/q 做部分分式分解
🖥️ dsolve({diff(y(x),x)+4*y(x)=cos(x)+x, y(0)=0}, y(x))　← 一阶 IVP
🖥️ dsolve({y(x)*diff(y(x),x$2)+diff(y(x),x)^2=0, y(0)=3, D(y)(0)=9}, y(x))　← 二阶 IVP，初始导数写 D(y)(0)
🖥️ product(x^2+k+9*x, k=190..1500)　← 连乘 Π；也可用 mul(...)
🖥️ coeff(series(exp(4*x)/(1-x), x=0, 8), x, 7)　← 取 Taylor 展开中 x^7 的系数
❌ 常见错误
❌ 乘法漏写 *：6x^5 要写 6*x^5，sin(9x-y) 要写 sin(9*x-y)
❌ 幂次用错：x² 要写 x^2，不能写 x2 或 x²
❌ Maple 输出题不要粘 y(x)=，题目要求只填右侧表达式时要删掉左边
❌ product / series 题不要加赋值 := 或分号 ;，Mobius 通常只要表达式本身
❌ 10位有效数字题必须从 Maple 复制答案，Python 最后1-2位可能偏差

TOOLS1 · 工程图读图与标注
📝 TOOLS1 Quiz
▼
名义尺寸（Nominal Dimension）= 图纸上标注的理论值，不含公差；未标出的尺寸用总长减去已知段求得，如 D1 = 总长 − 已知段
通孔标注格式：Ø[直径] THRU — Ø 表示直径，THRU 表示贯穿整个零件，例 Ø10 THRU = 直径10mm通孔
沉头孔 ⌴（Counterbore）两行标注：上行 Ø[底孔直径] THRU，下行 ⌴ Ø[沉头直径] ▼[沉头深度]；⌴ = 平底扩孔，▼ = 深度
螺纹孔两行标注：上行 Ø[底孔直径] ▼[钻孔深度]，下行 M[尺寸]×[螺距] ▼[螺纹深度]；螺纹深度必须小于钻孔深度（底部留空间防止断刀）
ISO 公制螺纹格式：M[公称直径]×[螺距]，公称直径 = 螺纹外径，螺距 = 相邻牙距（mm），例 M5×0.8
📌 底孔与螺纹对照（必记）：Ø3.30 → M4×0.7；Ø4.20 → M5×0.8；Ø5.00 → M6×1.0；Ø6.80 → M8×1.25；规律：底孔直径 ≈ 公称直径 − 螺距
倒角标注：C[尺寸]×45 = 45°倒角，如 C1×45 表示1mm宽的45°倒角
锥度标注：C[尺寸]×45 TAPER = 外锥面，每边收缩该尺寸，如 C2×45 TAPER
多孔前缀：2×、4× 表示该特征重复数量，如 4×Ø6.2 THRU = 四个直径6.2mm通孔
📌 符号速查：Ø=直径；▼=深度；THRU=通孔；⌴=平底沉头孔；⌵=锥形锪孔；M=公制螺纹；C=倒角/锥度

TOOLS1 · 游标卡尺测量方法
📝 TOOLS1 Quiz
▼
游标卡尺（Vernier Caliper）三部位：外爪（outer jaws）量外径/厚度/总长；内爪（inner jaws）量孔径/内径；深度杆（depth rod）量孔深/槽深；主尺精度1mm，游标尺精度0.02mm
读数三步：① 主尺——游标0线左侧整数mm值 ② 游标——找与主尺对齐的格数 × 精度（如第12格对齐 = 12×0.02 = 0.24mm）③ 两者相加 = 最终读数
量厚度/总长（T1、L4）用外爪：夹住零件外表面两侧，轻轻锁紧后读数
量孔径/沉头孔直径用内爪：将内爪伸入孔中撑开至刚好接触孔壁两侧，内爪必须垂直孔轴线，找最大值读数
量钻孔深/沉头深度用深度杆：卡尺端面完全平贴零件表面，深度杆插入孔中顶到底，读数即为深度
量螺纹深度用深度杆：插入螺纹孔，感觉到阻力停止（螺纹终止处），该位置读数为螺纹有效深度
沉头深度技巧：深度杆直接测表面到沉头底面距离；或总孔深 − 底孔深 = 沉头深度
❌ 常见错误：内爪未垂直孔轴（读数偏大）；深度杆未顶到底就读；读数时卡尺滑动了；游标读错对齐线
📌 测量规范：同一尺寸量3次取平均；量孔径时在不同方向各量一次确认圆度；深度杆端面必须完全贴合表面

外径千分尺 Outside Micrometer
▼
外径千分尺用于测外径/厚度/轴径，精度0.01mm，比游标卡尺（0.02mm）更高，但每把量程只有25mm（如0-25mm、25-50mm）
结构六部件：砧座（anvil）固定；测微螺杆（spindle）活动；套筒（sleeve）刻主刻度；套管（thimble）旋转刻25格；锁紧螺母（lock nut）；棘轮（ratchet）控制力度防过压
读数三步（0.01mm精度）：① 读套筒——水平线上方整数mm，再看水平线下方是否露出0.5mm格 ② 读套管——对齐水平线的格数 × 0.01mm ③ 相加。例：套筒7.5mm + 套管12格×0.01 = 7.62mm
使用步骤：① 棘轮打开比零件稍大 ② 零件放入砧座和螺杆之间 ③ 转棘轮（不转thimble）直到听到"咔"声停 ④ 锁紧读数
📌 归零检查（Zero Check）：两端闭合后读数应为0.00mm，不为零要调零或记录偏差后修正结果
❌ 常见错误：直接转thimble施力过大导致读数偏小；没归零检查；漏看套筒0.5mm刻线；零件倾斜放置
外径用千分尺（精度高），孔径/深度用游标卡尺内爪/深度杆，两者互补使用

公差与配合 Tolerances & Fits
▼
公差（Tolerance）= 允许的尺寸变动量，因为加工不可能绝对精确。公差 = 上偏差 − 下偏差，永远为正值
基本术语：公称尺寸（Nominal）= 图纸标注理论值；上偏差 = 最大允许值 − 公称值；下偏差 = 最小允许值 − 公称值。例：25⁺⁰·⁰²₋₀.₀₁ → 最大25.02，最小24.99，公差0.03mm
IT公差等级：IT1最精密 → IT18最粗糙；IT6/IT7用于精密配合面；IT11/IT12用于一般配合；IT14用于自由公差（粗加工）；等级数字越小公差带越窄要求越高
三种配合类型：间隙配合（Clearance fit）轴 < 孔，总有间隙，如 H7/g6；过渡配合（Transition fit）可能间隙可能过盈，如 H7/k6；过盈配合（Interference fit）轴 > 孔，需压入，如 H7/p6
基孔制（Hole basis）最常用：孔的下偏差固定为0（字母H），通过改变轴的公差带位置得到不同配合。读法 H7/g6：H7=基准孔（IT7级），g6=轴（负偏差，IT6级）→ 间隙配合
📌 常见配合速记：H7/f7 宽松间隙；H7/g6 小间隙精密滑动；H7/h6 最小间隙定位；H7/k6 过渡轻压；H7/p6 小过盈压配；H7/s6 大过盈紧压
自由公差（General Tolerance）：图纸标题栏注明 ISO 2768-f/m/c，未单独标注的尺寸自动套用。f=fine精，m=medium中，c=coarse粗
❌ 易混淆：公差永远是正数（范围大小）；偏差可正可负（偏移方向）；"公差0.02mm"不是指尺寸是0.02，而是上下限相差0.02mm

测量概念与误差 Measurement Concepts
▼
准确度（Accuracy）= 测量值与真实值的接近程度；精密度（Precision）= 多次测量结果的重复性。可以精密但不准确（系统偏差），也可以准确但不精密（每次结果不同）
分辨率（Resolution）= 仪器能读出的最小单位：钢尺 1mm；游标卡尺 0.02mm；数显卡尺/千分尺 0.01mm；分辨率越小仪器越精细
系统误差（Systematic Error）：方向固定、有规律，如仪器未归零、温度导致膨胀。可通过校准/归零消除
随机误差（Random Error）：每次测量随机波动，如读数判断不同、握力不稳。通过多次测量取平均值减小
视差误差（Parallax Error）：眼睛不垂直刻度线时产生。读游标卡尺时眼睛正对刻度线，不能斜看
Abbe 原理：测量轴线与被测尺寸应在同一直线，否则角度误差会放大。千分尺符合此原理；游标卡尺量程较大时略有偏差
标准测量温度为20°C，金属受热膨胀。精密测量前零件和量具需在同温环境放置一段时间使温度均匀
测量不确定度（Uncertainty）表示可信范围，如 25.34 ± 0.02mm；不确定度 ≥ 仪器分辨率的一半
📌 操作规范：测前清洁接触面；同位置量3次取平均；同时记录环境温度；量具用完归零存放

表面粗糙度与螺纹测量 Surface Finish & Threads
▼
表面粗糙度（Surface Roughness）用 Ra（算术平均粗糙度）表示，单位 μm（微米），Ra越小越光滑，加工成本越高
Ra 值范围参考：Ra 0.1–0.4μm 磨削研磨（镜面）；Ra 0.8–1.6μm 精车精铣（配合面）；Ra 3.2–6.3μm 普通车削（一般面）；Ra 12.5–25μm 粗加工/铸造面
图纸粗糙度符号：√ 旁标 Ra 值，如 √Ra 1.6；带圆圈的 √ 表示所有面统一粗糙度；括号里的是未标注面的默认值
螺距规（Thread Pitch Gauge）：一组刻有不同齿距的薄片，逐片插入螺纹，完全咬合无间隙的那片数值就是该螺纹的螺距
螺纹识别四步：① 螺距规确认螺距 ② 游标卡尺量外径（公称直径）③ 查对照表得完整规格 M直径×螺距 ④ 用标准螺栓/螺母试配最终确认
通止规（Go/No-Go Gauge）：检验孔/轴是否在公差范围的专用量具。Go端（通端）必须能通过；No-Go端（止端）不能通过。两个条件同时满足 = 合格
其他量具：钢直尺精度1mm量长度；组合角尺量90°/45°；量角器量任意角；百分表（Dial indicator）测圆度/平面度/跳动量
📌 量具保养：用后擦干净防锈；卡尺存放时两爪留微小间隙；千分尺两端留0.5mm间隙防热胀卡死；避免摔落碰撞

CAD 基础
▼
先读工程图：找主视图、基准面、总长总宽总高、孔位和对称关系。

草图、约束与尺寸
Sketch
▼
草图目标：线条全部变黑，状态显示完全定义。
Sketch goal: all sketch geometry should turn black and show as fully defined.
优先使用几何关系：水平、垂直、相等、同心、相切、重合和对称。
Use geometric relations first: horizontal, vertical, equal, concentric, tangent, coincident and symmetric.
尺寸不要重复约束：一个长度只用一个主尺寸控制，避免过定义。
Avoid duplicate control dimensions because repeated constraints can over-define the sketch.

Assembly
▼
装配第一步：插入第一个零件并固定，通常固定底板或基准件。

Step-by-step：一把手流程
▼
1. Report skeleton：先建 20 页以内报告骨架：cover、contents、background、selected structure、geometry、static、impact、stress、critical diameter、comparison、reflection。
2. Node map：把选定结构的节点、杆件、支座、load nodes、impact node 全部编号。每根杆件起一个名字，例如 AB、AC、BD。
3. Assumptions：连接为 pin-jointed；杆件只受 axial force；材料均为 steel；圆截面 d = 30 mm；忽略或计入自重的理由写清楚。
4. Static FBD：画整体 free-body diagram，用 ΣFx=0、ΣFy=0、ΣM=0 求支座反力，再用 method of joints / sections 求每根杆件力。
5. Impact FBD：先由能量/运动学求 equivalent impact force，再把它放到指定 impact node，重复一次 reactions + member forces。
6. Member table：做表格：member、N_static、T/C、N_dynamic、T/C、σ_static、σ_dynamic、pass/fail。这张表是报告核心。
7. Critical member：找 |N| 最大的杆件。用 d_min = √(4N / (πσ_allow)) 分别算 static 和 dynamic 的最小直径。
8. Second method：用 Excel/Python/MATLAB/Space Gass/AI 复核 reactions 和 member forces；写清楚输入、假设、差异原因。
9. Reflection：150–250 words，重点写：哪个方法更容易出错、动力载荷如何改变 critical member、设计直径为什么变大。

Checklist：交之前逐项打勾
▼
报告是单个 PDF，最多 20 页 A4；页边距、页码、figure/table label、单位都要完整。
有 selected structure 的图：尺寸、节点编号、杆件编号、支座类型、静载节点、冲击节点。
Static 和 impact 两套 FBD 都有；support reactions 不只给答案，要有关键方程。
每根 member force 都有 Tension / Compression 标记，最后汇总到表格。
Stress check 用 σ=N/A；pass/fail 写清楚；critical member 和 minimum diameter 分 static / dynamic 两套。
第二种方法要有截图或输出，不要只说“我用软件算了”。差异要解释，不能假装完全一样。
Reflection 不写鸡汤，写工程判断：哪里最不确定、哪个 load case 控制设计、下次会怎么建模。
