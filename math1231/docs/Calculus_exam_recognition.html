1. 微分方程建模：先问“什么在增加，什么在减少”

所有本套现实模型，都先写成：

变化率 = 正贡献 - 负贡献

不要一上来就积分。先确认变量、单位和每一项的物理意义。

单位检查是最简单的防错方法

如果 x(t) 是“克”，那么 dx/dt 必须是“克/分钟”。

如果 V(t) 是“人数”，那么 dV/dt 必须是“人/月”。

浓度 × 流量 = 物质流率，例如 (g/L)×(L/min)=g/min。

考试一眼识别：题目出现 reported, added, inflow, deposit → 正项；出现 recovery, death, outflow, payment → 负项。

2. 盐水混合题：固定四步法

题型关键词

tank、brine、litres、grams per litre、mixed thoroughly、inflow/outflow。

四步固定模板

定义 x(t)：时刻 t 水箱中溶质总量。

算体积 V(t)=V₀+(流入流速-流出流速)t。

算流入溶质率 = 外界浓度 × 流入流速。

算流出溶质率 = 箱内浓度 x/V(t) × 流出流速。

x'(t) = (外界浓度)(流入流速) - [x(t)/V(t)](流出流速)

本套代表题

初始 1500 L、7000 g 盐；流入 7 g/L，15 L/min；流出同速。

V(t)=1500，流入=105，流出=x/100

x' = 105 - x/100，x(0)=7000

完整解：x(t)=10500-3500e^{-t/100}。长期趋近 10500 g。

最常见错误

把 7 g/L 直接当成 7 g/min。

把 x/1500 当成流出率；它只是浓度，还要乘 15 L/min。

忘记先判断体积是否变化。

3. 万能模型 y' = a - by

病毒、未破案件、盐水、终端速度，本质全是同一个模型：固定增加 a，按当前数量比例减少 by。

y' = a - by

最重要的第一步：找平衡值

平衡时数量不再变化，所以令 y'=0：

y_eq = a/b

带初值的万能答案

y(t)=a/b + (y₀-a/b)e^{-bt}

你可以把它理解成：最终值 +（初始值 - 最终值）×逐渐消失的指数项。

如何一眼判断增还是减

若 y₀<a/b，函数向上增加，靠近平衡值。

若 y₀>a/b，函数向下降低，靠近平衡值。

指数 e^{-bt} 在 b>0 时会趋近 0。

考试一眼识别：看到 y'=常数-系数×y，优先用平衡值公式，不必每次从头积分。

4. 这类方程为什么既 linear 又 separable

Linear 的识别

能整理成下面形式，就是一阶线性：

y' + P(t)y = Q(t)

y 只能一次方，不能出现 y²、sin(y)、yy' 等。

Separable 的识别

能把 y 放一边、t 放另一边，就是可分离：

dy/f(y) = g(t)dt

例子

x' = 40-x/100 = (4000-x)/100

它既可写成 x'+x/100=40，所以 linear；也可写成 dx/(4000-x)=dt/100，所以 separable。

考试一眼识别：选择题问 “select all that are true” 时，不要以为一种 ODE 只能属于一个类别。

5. 积分因子法：每一步只做一件事

固定流程

先整理成 y'+P(t)y=Q(t)。

积分因子 μ(t)=e^{∫P(t)dt}。

整条方程乘 μ。

左边识别成 (μy)'。

两边积分，再除以 μ。

最后代初值。

为什么左边会合成乘积导数

(μy)' = μy' + μ'y

因为 μ 被专门选成 μ'=Pμ，所以 μy'+Pμy 正好等于 (μy)'。

代表例子

x' + (7/50)x = 20

μ=e^{7t/50}

(xe^{7t/50})' = 20e^{7t/50}

x=1000/7 + Ce^{-7t/50}

积分因子法最容易错的地方

移项后 P(t) 的正负号。

积分因子指数里漏掉 t。

积分 e^{kt} 时忘记除以 k。

最后除以 e^{kt} 后，常数项变成 Ce^{-kt}。

6. 下落物体：重力增加速度，阻力减少速度

基本模型

v' = g-kv

g 是重力造成的正贡献；kv 是与速度成正比的空气阻力。

通解

v(t)=g/k + Ce^{-kt}

终端速度

长期时指数项消失：

v_terminal = g/k

也可以直接令 v'=0：g-kv=0。

如果 initially at rest

v(0)=0，所以 C=-g/k：

v(t)=(g/k)(1-e^{-kt})

参数含义

g：由重力决定。

k：由空气阻力强弱决定。

C：由初始速度决定。

初始条件影响过渡过程，不影响终端速度。

7. 由速度求位置：再积分一次

速度就是位置的导数：

x'(t)=v(t)

若 v=(g/k)(1-e^{-kt})，则：

x=gt/k + (g/k²)e^{-kt} + K

再用 x(0)=h 得 K=h-g/k²，最终：

x(t)=h+(g/k²)(kt+e^{-kt}-1)

最容易错的符号

∫e^{-kt}dt=-(1/k)e^{-kt}

原速度中本来还有一个减号，因此最后指数项是正的。

8. “速度与已下落距离成正比”为何矛盾

x'=k(h-x)

它既 linear 又 separable。非平衡解可写为：

x=h-e^{-kt+C}

若初始 x(0)=h，则会要求 e^C=0，但指数永远大于 0。真正满足初值的唯一解是 x(t)=h，即物体永远不动。

考试一眼识别：遇到分离变量时除以 h-x，可能会丢掉平衡解 h-x=0；必须单独检查。

9. 利息题：先分清单利、离散复利、连续复利

单利

A(t)=P(1+rt)

只对最初本金计息，增长是直线。

每年复利 n 次

A(t)=P(1+r/n)^{nt}

每期利率是 r/n，总期数是 nt。

连续复利

A'=rA  ⇒  A(t)=A₀e^{rt}

增长速度与当前余额成正比。

比较题怎么做

不要只看利率大小。把两种方案的最终金额分别算出来再比较。

代表结果

20% 单利 5 年：2000；16% 月复利 5 年：约 2213.81 → 复利更好。

10% 单利 5 年：1500；6% 月复利 5 年：约 1348.85 → 单利更好。

3% 单利 5 年：1150；2.9% 月复利 5 年：约 1155.84 → 复利略好。

10. 连续复利是怎样从差商来的

一个长度为 1/n 年的周期内：

ΔA = A(1+r/n)-A = Ar/n

Δt = 1/n

ΔA/Δt = rA

当周期越来越短，平均变化率趋近瞬时变化率：

dA/dt = rA

所以 A(t)=Ce^{rt}，而 C=A(0)，代表初始本金。

11. 持续存款与贷款：固定流量 + 比例利息

持续存款

A'=rA+D

rA 是利息；D 是每年持续存入的固定金额。

本套代表题

A'=0.04A+5000，A(0)=18000

A(t)=143000e^{0.04t}-125000

4 年后约 42812。

持续还贷款

L'=rL-P

rL 让欠款增加；P 是固定还款，必须是负项。

本套代表题

L'=0.075L-9000，L(0)=40000

L(t)=120000-80000e^{0.075t}

4 年后约欠 12011。模型只适用于贷款还清之前。

最常见错误

把每年存入 5000 写成 5000t 放进导数右边。正确的速率项是 5000。

贷款还款写成 +9000。正确是 -9000。

积分因子符号与标准形式不一致。

12. 极限、平衡值与长期行为

最快方法 1：令导数为 0

y'=a-by ⇒ y_eq=a/b

最快方法 2：看指数项

e^{-bt}→0  (t→∞, b>0)

所以通解只剩平衡值。

平衡值的现实解释

病毒：新增病例 = 康复/离开病例。

未破案件：新增案件 = 被清除案件。

盐水：盐流入率 = 盐流出率。

速度：重力 = 空气阻力。

15. 考前最后一页：必须背住

混合：x' = rate in - rate out

箱内浓度 = x(t)/V(t)

线性 ODE：y'+P(t)y=Q(t)

积分因子：μ=e^{∫P(t)dt}

万能模型：y'=a-by

平衡值：y_eq=a/b

初值解：y=a/b+(y₀-a/b)e^{-bt}

终端速度：g/k

单利：P(1+rt)

持续还款：L'=rL-P

考试一眼识别：最终口诀：先建模，再分类；常数增加、比例减少就找平衡；linear 用积分因子；问长期值就令导数为 0；利息先分清单利、离散复利、连续复利。
