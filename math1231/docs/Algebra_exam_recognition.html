全章一句话

线性映射就是一台“保持加法和倍数”的机器；矩阵就是这台机器的操作说明书。


1. 线性映射到底是什么

把 T 想成一台机器：输入一个向量，输出另一个向量。所谓“线性”，只要求它严格遵守两条规则。

T(u + v) = T(u) + T(v)

T(cu) = cT(u)

T(au + bv) = aT(u) + bT(v)

最通俗理解

输入加在一起，输出也能分开相加。

输入乘几倍，输出也乘几倍。

只要题目说 linear map，这三条就可以直接使用。


标准基：二维世界的“向右”和“向上”

e₁ = (1,0),    e₂ = (0,1)

(x,y) = x(1,0) + y(0,1)

因此，只要知道机器怎样处理 (1,0) 和 (0,1)，整个二维线性映射就全部确定。

T(x,y) = xT(1,0) + yT(0,1)

看到这些关键词，立刻想到

题目给 T(1,0) 和 T(0,1)：马上写 T(x,y)=xT(1,0)+yT(0,1)。

题目给 T(1,0) 和 T(1,1)：先用 T(0,1)=T(1,1)-T(1,0)。

题目问 could T still be linear：用已知线性关系算出唯一结果，与题目给的结果比较。


2. 已知基向量的像，求任意向量

典型题型：

T(1,0)=(-1,4),    T(0,1)=(4,-4)

1. 先写万能式：T(x,y)=xT(1,0)+yT(0,1)。

2. 把已知向量代进去：x(-1,4)+y(4,-4)。

3. 对应坐标相加，得到 T(x,y)=(-x+4y, 4x-4y)。

4. 问具体点时，再把 x、y 代入。

T(x,y)=(-x+4y, 4x-4y)

考试秒杀口诀

给基像 → 线性组合。

先写一般公式 → 再代具体数字。

不要每问一个点就重新从头算。


特殊情况：给 T(1,0) 和 T(1,1)

(1,1)=(1,0)+(0,1)

T(0,1)=T(1,1)-T(1,0)

例如 S(1,0)=(6,-1)，S(1,1)=(5,0)，则：

S(0,1)=(5,0)-(6,-1)=(-1,1)

S(x,y)=(6x-y, -x+y)

3. 矩阵就是“基向量的像排成列”

若：

T(1,0)=(a,c),    T(0,1)=(b,d)

那么矩阵是：

A = [[a,b],[c,d]] = [ T(e₁)  T(e₂) ]

最重要的方向感

第一列 = T(1,0)。

第二列 = T(0,1)。

是“列”，不是“行”。


矩阵乘向量：永远是行乘列

[[a,b],[c,d]] [x,y]ᵀ = [ax+by, cx+dy]ᵀ

1. 矩阵第一行与向量点乘，得到第一个输出坐标。

2. 矩阵第二行与向量点乘，得到第二个输出坐标。

尺寸检查

2×2 矩阵乘 2×1 向量，结果必须是 2×1。

5×4 矩阵乘 4×1 向量，结果必须是 5×1。

中间尺寸必须相同。


看到矩阵后，先写坐标规则

M=[[3,0],[1,2]]  ⇒  T(x,y)=(3x, x+2y)

后面无论问 C、D、E 哪个点，直接代入这个规则，不要重复做矩阵乘法。

4. 特殊矩阵：看到就要秒懂几何意义

矩阵

坐标规则

几何意义

I = [[1,0],[0,1]]

(x,y)→(x,y)

什么都不变

−I = [[−1,0],[0,−1]]

(x,y)→(−x,−y)

绕原点旋转 180°

kI

(x,y)→(kx,ky)

按 |k| 倍缩放；k<0 还会反向

[[1,0],[0,−1]]

(x,y)→(x,−y)

关于 x 轴反射

[[−1,0],[0,1]]

(x,y)→(−x,y)

关于 y 轴反射


常见图形判断

上下左右都反了：通常是 −I，也就是 180° 旋转。

只有 y 变号：关于 x 轴反射。

只有 x 变号：关于 y 轴反射。


5. 三维线性映射：只是多一个基向量

e₁=(1,0,0), e₂=(0,1,0), e₃=(0,0,1)

T(x,y,z)=xT(e₁)+yT(e₂)+zT(e₃)

如果题目让你把 (−7,8,5) 写成标准基的线性组合，系数直接就是：

(−7,8,5)=−7e₁+8e₂+5e₃

不要过度思考

“standard basis coefficients” 就是原向量的坐标。

二维是 [x,y]，三维是 [x,y,z]。


判断“还能不能是线性的”

一旦 T(e₁)、T(e₂)、T(e₃) 已知，整个线性映射已经唯一确定。

T(−7,8,5)=−7T(e₁)+8T(e₂)+5T(e₃)

如果题目另外给了一个不同结果，即使只差 1，也不可能仍然线性。

6. 房屋与图形变换题：算关键点，不要凭感觉

房屋题通常使用这些关键点：

O=(0,0), A=(1,0), B=(0,1), C=(1,1)

1. 先写变换规则 T(x,y)。

2. 计算 T(O)、T(A)、T(B)、T(C)。

3. 由于 C=A+B，可用 T(C)=T(A)+T(B) 快速检查。

4. 再计算屋顶点 D、烟囱点 E。

5. 用外框筛选，再用门、窗、烟囱位置确认。

T(0,0)=(0,0)

铁律：线性映射不平移原点

任何线性映射都满足 T(0)=0。

如果选项中原点跑到别处，那不是纯线性变换。


从变换后的图反推矩阵

原来向右的边代表 e₁=(1,0)，变换后这条边的向量就是 T(e₁)。

原来向上的边代表 e₂=(0,1)，变换后这条边的向量就是 T(e₂)。

把这两个向量作为矩阵的第一列和第二列。

A=[T(e₁)  T(e₂)]

7. 已知输出，反求输入：解 Ax=b

题目常写：Which point gets sent to (1,−2)? 意思是“哪个输入经过变换后得到这个输出？”

A x = b

1. 把未知输入设为 x=(x,y)。

2. 把变换规则等于题目给的输出。

3. 比较每个坐标，解联立方程。

4. 若矩阵可逆，也可直接用 x=A⁻¹b。

看到这些词立刻反解

gets sent to

maps to（当未知的是输入时）

go backwards

ingredient vector from nutritional vector


8. 逆矩阵：把变换倒着做

如果 A 把输入变成输出：

y = Ax

那么逆矩阵把输出还原成输入：

x = A⁻¹y

A⁻¹ = 1/(ad−bc) · [[d,−b],[−c,a]]

能不能求逆，看行列式

若 det(A)≠0，A 可逆。

若 det(A)=0，图形被压扁，无法唯一还原输入。


9. 行列式与面积变化

det([[a,b],[c,d]]) = ad−bc

面积倍数 = |det(A)|

det(A)

意味着什么

> 0

面积乘 det(A)，方向未翻转

< 0

面积乘 |det(A)|，方向发生翻转

= 0

被压成一条线或一个点，面积为 0


最大易错点

题目问 area factor 时一定取绝对值。

公式是 ad−bc，不是 ac−bd。


10. 线性组合：找几份向量拼出目标

b = αv₁ + βv₂ + γv₃

本质：求 α、β、γ 分别拿多少份，才能加出目标向量 b。

1. 把 v₁、v₂、v₃ 作为矩阵的列。

2. 把未知系数写成列向量 (α,β,γ)。

3. 组成 M c = b。

4. 解这个方程组。

[v₁ v₂ v₃] [α,β,γ]ᵀ = b

现实题的翻译

配料 → 营养：y=Ax。

营养 → 配料：x=A⁻¹y。

向量作列，不作行。


11. 从两个非标准向量的像反求矩阵

有时题目不给 T(1,0)、T(0,1)，而给 T(1,1)、T(1,−1)。此时设：

T(x,y)=(ax+by, cx+dy)

T(1,1)=(a+b, c+d)

T(1,−1)=(a−b, c−d)

1. 把题目给的两个输出分别与上面两个表达式对应。

2. 得到四个关于 a、b、c、d 的方程。

3. 分别相加、相减求出四个系数。

4. 写出矩阵 [[a,b],[c,d]]。

快速解法

a=(“第一坐标两式相加”)/2。

b=(“第一坐标第一式减第二式”)/2。

c、d 同理。


12. 圆变椭圆：一定先求逆变换

原图满足 x²+y²=1，变换后新坐标为 (X,Y)。题目要的是关于 X、Y 的方程。

[X,Y]ᵀ = A[x,y]ᵀ

[x,y]ᵀ = A⁻¹[X,Y]ᵀ

1. 先由正向变换求出逆变换，把 x、y 表成 X、Y。

2. 把这些表达式代回旧方程 x²+y²=1。

3. 展开并整理。

绝对不要做

不能把正向公式 X=...、Y=... 直接当成 x、y 代入旧圆方程。

问“新坐标的方程”时，必须使用逆变换。

15. 最常见的失分点

把 T(e₁)、T(e₂) 放成行，而不是列。

矩阵乘向量时没有“行乘列”。

题目问反求输入，却继续做正向变换。

面积倍数忘记对 det 取绝对值。

图形题只看外框，不看门、窗、烟囱。

曲线变换直接代正向公式，而不是先求逆。

分数通分时出错，例如 7/8+3 应写成 7/8+24/8。

把两位有效数字误认为保留两位小数。

Maple 中把列表 [ ] 和向量 < > 混淆。

[[a,b],[c,d]][x,y]ᵀ=[ax+by,cx+dy]ᵀ

x=A⁻¹b

det(A)=ad−bc

曲线变换：旧坐标=A⁻¹·新坐标
